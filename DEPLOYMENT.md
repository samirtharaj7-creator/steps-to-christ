# Deployment

This is a static GitHub Pages site for `stc.mybibleexplorer.com`.

1. Publish this folder to the `main` branch of its GitHub repository.
2. In GitHub Pages, deploy from the root of the `main` branch.
3. At the DNS provider for `mybibleexplorer.com`, create a CNAME record named `stc` pointing to `samirtharaj7-creator.github.io`.
4. After GitHub verifies the custom domain, enable **Enforce HTTPS**.

The root `CNAME` file must remain in the published branch.
